Design a premium, modern, highly engaging Arabic educational mobile application called **"ذاكر معي" (Zakker Ma3aya)** for Egyptian students from **4th Grade Primary School to 3rd Grade Secondary School**.

The app uses AI to explain Egyptian school curriculum lessons through AI-generated presentations, visual explanations, quizzes, progress tracking, gamification, and personalized study planning.

## CORE DESIGN DIRECTION

Create a UI that feels like a combination of:

* Modern EdTech platform
* Gamified learning app
* AI assistant
* Clean premium startup product

The design must be **exciting enough to motivate students to study**, but NOT childish.

Use:

* Modern rounded cards
* Soft shadows
* Large readable typography
* Friendly illustrations
* Smooth visual hierarchy
* Progress indicators
* Gamification elements
* Micro-interactions
* Modern icons
* Arabic RTL layout everywhere

The application should feel polished enough to compete with major educational applications.

## BRAND

App name:
**ذاكر معي**

Arabic tagline:
**افهمها، ذاكرها، وخلّي مستواك يتكلم عنك.**

Visual personality:
Friendly + Smart + Motivational + Modern + Energetic

Use a modern Arabic font such as:
**Tajawal / IBM Plex Sans Arabic / Cairo**

Use a professional educational color system:

* Primary: energetic blue
* Secondary: purple
* Accent: yellow/gold for rewards
* Success: green
* Warning: orange
* Error: red
* Background: very light neutral
* Dark text with excellent contrast

Do NOT make every screen extremely colorful.
Use colors strategically to create hierarchy.

# IMPORTANT PRODUCT RULES

There are TWO separate reward currencies:

### POINTS 🏆

Used for:

* XP / Level
* Achievements
* Rankings
* Learning progress

### COINS 🪙

Used for:

* Unlocking additional lessons
* Earning through ads/rewards

NEVER combine Points and Coins into one balance.

The distinction must be obvious throughout the entire UI.
